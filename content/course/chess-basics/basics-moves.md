# Как ходят фигуры

## Цель

Научиться видеть законные маршруты фигур и препятствия на линии.

## Объяснение

Ладья ходит по прямым, слон — по диагоналям, ферзь сочетает оба движения, король ходит на одно поле, конь прыгает буквой «Г», пешка движется вперёд и бьёт по диагонали.

Аналогия: ладья — поезд по рельсам, слон — луч фонаря, конь — прыжок через забор.

## Пример

Конь на `f3` атакует `d4`, `d2`, `e5`, `g5`, `h4` и `h2`, даже если между ним и целью стоят фигуры.

## Практика

Для каждой фигуры назови все доступные поля из центра пустой доски.
