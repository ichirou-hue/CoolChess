# CoolChess Backend API

Бэкенд-сервис платформы **CoolChess**, реализованный на FastAPI. Обеспечивает аутентификацию учеников, выдачу шахматных задач и инференс нейросетевого шахматного движка **Maia-3** для игры с ботом разного уровня сложности.

---

## Стек технологий

* **Язык**: Python 3.13
* **Фреймворк**: FastAPI + Pydantic v2
* **ASGI-сервер**: Uvicorn
* **ML / Шахматы**: PyTorch, `maia3`, `python-chess`
* **Модель бота**: Maia-3 (5M параметров, трансформерная архитектура с прогнозированием ходов под конкретный Elo)

---

## Структура директории

```text
backend/
│
├── server.py              # Точка входа ASGI-сервера, CORS-политики, регистрация роутеров
├── models/
│   └── maia3-5m.pt        # Локальный чекпоинт весов трансформера Maia-3
│

    ├── bot_routes.py      # Эндпоинт бота: POST /api/bot/move
    └── bot_service.py     # Инициализация Maia3UCIEngine и расчёт предсказаний
