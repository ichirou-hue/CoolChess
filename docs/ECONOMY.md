# Игровая экономика CoolChess

Источник истины — сервер (`backend/puzzles/rewards.py`, `backend/games/rewards.py`).
Клиент награды не считает, только отображает ответ API.

## Уровень

```
level(xp) = isqrt(xp // 100) + 1
```

Пороги: `0–99 → 1`, `100–399 → 2`, `400–899 → 3`, `900–1599 → 4`, `1600+ → 5`.
Уровень пересчитывается при каждом начислении (`calculate_level`).

## Задачи: фиксированные тиры

Награда зависит **только от рейтинга задачи**, не от силы игрока
(`get_fixed_puzzle_rewards`):

| Рейтинг задачи | XP | Монеты | Elo |
|---|---|---|---|
| ≤ 1199 | 15 | 5 | +5 |
| ≤ 1599 | 30 | 10 | +8 |
| ≤ 1999 | 50 | 20 | +12 |
| ≤ 2399 | 80 | 35 | +16 |
| 2400+ | 120 | 50 | +20 |

## Матчи: формула Elo (K=32)

```
expected = 1 / (1 + 10 ^ ((bot_elo − user_elo) / 400))
elo_delta = round(32 × (actual − expected))
```

`actual`: победа `1.0`, ничья `0.5`, поражение/сдача `0.0`. Elo снизу
ограничен значением 100. Сложность-тир маппится в рейтинг:
`1→1100, 2→1300, 3→1500, 4→1700, 5→1900` (можно передать Elo напрямую).

| Результат | XP | Монеты |
|---|---|---|
| Победа | `max(20, bot_elo / 15)` (1500 Elo → 100 XP) | `max(5, bot_elo / 50)` (1500 Elo → 30) |
| Ничья | `max(10, bot_elo / 35)` | `max(2, bot_elo / 120)` |
| Поражение | 10 (утешительные) | 0 |
| Сдача (`resign`) | 0 | 0 (Elo — как за поражение) |

## Защита от фарма

- Повторное решение задачи: `already_solved: true`, наград `0`
  (составной PK `(user_id, puzzle_id)` в `user_solved_puzzles`).
- Гонка параллельных `solve`-запросов гасится через `IntegrityError` + rollback.
- Сдача партии (`resign`) не приносит XP/монет по дизайну.
- Роль и связанные привилегии меняет только superuser — накрутка через
  регистрацию невозможна (поле `role` убрано из схем регистрации/обновления).
