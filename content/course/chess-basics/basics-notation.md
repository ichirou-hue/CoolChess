# Шахматная нотация

## Цель

Уметь записать и восстановить партию по ходам.

## Объяснение

В записи используются буквы фигур, координаты полей, `x` для взятия, `+` для шаха и `#` для мата. Пешка записывается без буквы: `e4`.

Аналогия: нотация — это GPS-трек партии. По нему можно вернуться в любую позицию.

## Пример

`Сb5` — слон пришёл на b5, `Кxf7+` — конь взял фигуру на f7 с шахом, `0-0` — короткая рокировка.

## Практика

Запиши первые десять ходов партии и попробуй восстановить позицию только по записи.
