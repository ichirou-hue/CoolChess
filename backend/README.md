# Backend-разработчику

## Как запустить сайт локально

Сейчас отдельного backend ещё нет. Сайт запускается из папки `frontend/`.

Нужен установленный Node.js. После этого открой PowerShell в папке проекта и выполни команды по очереди:

```powershell
cd frontend
npx pnpm@11.19.0 install
npx pnpm@11.19.0 dev
```

После последней команды открой адрес, который появится в терминале. Обычно это:

```text
http://localhost:5173
```

`install` скачивает зависимости проекта. Его нужно выполнить только после первого скачивания проекта или после изменения `package.json`.

## Как остановить сайт

В том же окне PowerShell нажми:

```text
Ctrl + C
```

## Как проверить сборку

```powershell
cd frontend
npx pnpm@11.19.0 build
```

Если в конце написано `built`, frontend собран правильно.

## Что делать с backend

Когда появится серверный код, размещай его в этой папке `backend/`. Frontend останется в `frontend/` и будет обращаться к API backend.

Сейчас frontend работает без сервера: авторизация демонстрационная, а часть прогресса хранится в браузере.

Описание будущих адресов авторизации находится в [docs/auth-contract.md](../docs/auth-contract.md).
