# CoolChess

Упрощённая шахматная платформа для онлайн-школы.

Согласованный scope прототипа находится в [docs/product-scope.md](docs/product-scope.md).

Проект рассчитан на один режим — ученика — и работает без backend: шахматная партия запускается локально в браузере, остальные данные пока mock или localStorage.
