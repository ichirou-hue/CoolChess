# Границы frontend и остальных частей

Главное правило проекта: если файл нужен браузеру или нужен для сборки React-приложения, он находится в `frontend/`.

## Что входит во frontend

| Путь | Назначение |
| --- | --- |
| `frontend/src/main.tsx` | точка входа и активные страницы приложения |
| `frontend/src/app/` | маршрутизация и общая логика приложения |
| `frontend/src/features/` | отдельные функции, например авторизация |
| `frontend/src/shared/` | общие библиотеки и временное состояние ученика |
| `frontend/src/data/` | данные, которые сейчас нужны интерфейсу: курс, статьи и визуальные позиции |
| `frontend/src/styles.css` | глобальные стили и дизайн CoolChess |
| `frontend/public/` | логотип и JSON-индекс задач, доступные браузеру |
| `frontend/index.html` | HTML-точка входа Vite |
| `frontend/package.json` | frontend-зависимости и команды запуска |
| `frontend/vite.config.ts` | настройки Vite и Tailwind |
| `frontend/tsconfig*.json` | настройки TypeScript |
| `frontend/pnpm-lock.yaml` | зафиксированные версии пакетов |

## Что не входит во frontend

| Путь | Назначение |
| --- | --- |
| `backend/` | будущий API, база данных, авторизация и серверная логика |
| `content/` | исходные Markdown-статьи курса для редакторов и будущей CMS |
| `docs/` | документация для команды и договорённости между frontend/backend |
| `scripts/` | Python-скрипты импорта задач и проверки статей |
| `data/` | исходные большие архивы, например полный дамп задач Lichess |
| `README.md` | общая инструкция по всему репозиторию |

## Важное различие

`frontend/src/data/` — это маленький runtime-слой: данные уже подготовлены и нужны интерфейсу прямо сейчас.

`content/` — это редакторский источник знаний. Позже backend или CMS сможет читать статьи оттуда и отдавать их frontend через API.

`frontend/public/data/puzzles.json` — облегчённая копия задач для браузера. Полный исходный архив остаётся в `data/source/` и в GitHub не отправляется.

## Локальные служебные папки

`node_modules/`, `dist/`, `.pnpm-store/`, `.tools/` и `_docx_render/` не являются исходным кодом и не должны добавляться в GitHub. Они нужны только на компьютере разработчика или создаются автоматически.

После перестройки команды запуска выполняются из `frontend/`:

```powershell
cd frontend
npx pnpm@11.19.0 dev
```
