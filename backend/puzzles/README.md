# 3. Датасет & API тактических задач (Puzzles)

Модуль парсинга, хранения и интерактивного решения тактических шахматных задач из базы Lichess с геймификацией наград.

## Стек и данные
* **Lichess Open Puzzle Database** (CSV/zst) — источник задач с реальными партиями, FEN и темами.
* **Скрипт импорта** — фильтрация, нормализация и загрузка партий в таблицу `puzzles`.
* **Система наград (`rewards.py`)** — динамический расчет начисления XP, монет и изменения рейтинга задачи.

## Структура данных
* `puzzles` — ID задачи, FEN, цепочка ходов UCI (`moves`), рейтинг задачи, популярность, теги тем (`themes`).
* `user_solved_puzzles` — связующая таблица истории решений с составным уникальным индексом `(user_id, puzzle_id)` для защиты от повторного фарма.

## Основные эндпоинты
* `GET /api/puzzles/random` — выдача случайной задачи с фильтрацией по рейтингу (`min_rating`, `max_rating`) и темам.
* `POST /api/puzzles/{id}/solve` — валидация хода игрока, начисление XP/монет/Elo и выставление флага `already_solved`.
