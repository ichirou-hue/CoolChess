# 2. Шахматный бот Maia & Inference

Модуль инференса нейросетевого шахматного движка Maia Chess для игры против модели с человекоподобным стилем под разный уровень мастерства.

## Стек и компоненты
* **python-chess** — валидация шахматных правил, парсинг FEN/UCI, генерация легальных ходов.
* **Веса Maia (ONNX / PyTorch / lc0)** — предобученные веса моделей под целевые рейтинги (Maia 1100, 1500, 1900).
* **Worker инференса** — фоновый обработчик генерации лучшего хода по переданной позиции.

## Принцип работы
1. Клиент передает текущую позицию партии в формате FEN и желаемый уровень сложности (target rating).
2. Движок валидирует состояние доски на отсутствие мата/пата.
3. Нейросеть оценивает вероятности ходов и выбирает ход, наиболее характерный для игроков выбранного рейтингового диапазона.
4. Клиент получает ход в формате UCI (например, `e2e4`) и обновленную позицию.

## Основные эндпоинты
* `POST /api/bot/move` — расчет и получение ответного хода бота по входному FEN.
* `GET /api/bot/levels` — список доступных уровней сложности и весов Maia.
